1. Reverse proxy with round-robin load balancing

Two mock upstreams (A and B, equal weight) sit behind the /api/* route. Each click is forwarded by the proxy; the JSON says which upstream answered. Click a few times and watch it alternate.

    2. Static file server with Range requests

    Fetches the first 100 bytes of range-demo.txt with a Range header. The static server answers 206 Partial Content with a Content-Range header instead of sending the whole file.

    click the button

    3. WebSocket tunnel

    Opens a WebSocket to /ws/echo. zeroproxy upgrades it natively and tunnels every frame to the upstream, which echoes it back through the tunnel.
